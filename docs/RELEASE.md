## 本地复核

自动化测试与验收工具将详细输出写入 `.data/release-archive/docs/`，它是可更新的本地工作副本；`snapshot/` 为不可覆盖的原始归档。需要旧数据的工具从该工作副本读取，缺少材料时提示恢复本地归档；不要为补证据自动发起真实模型请求。新克隆不含这些原始材料，常规单元测试与 Mock 测试不以私有归档为前提。

PostgreSQL 路径按 `VIBROWSER_PG_BIN`、PATH、Windows Program Files/PostgreSQL 依次解析；标准安装目录选择最高完整版本。显式配置无效直接报错，必须同时具备 pg_ctl、initdb、psql、createdb。路径含空格受支持。
