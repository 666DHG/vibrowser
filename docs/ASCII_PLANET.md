# 沉浸式纯文字星球

## 布局与操作

首页桌面右侧 64% 为字符场景，从顶部 32px 延伸至首页底部；文案主视觉高度保持 clamp(420px,58vh,680px)，球心位于场景 78% / 48%，球体直径为高度的 96%。右边裁切球体与星环，左边渐隐；左缘前 10% 完全透明，32% 处渐入；文案和卡片在前景独立排版，卡片以不透明背景保证阅读与点击。手机场景在文案下方，高度 280–360px。

所有星球、星环、星点和流星均写入 pre 文字网格。字体为 9px / 10px Courier New，禁用连字；根据容器计算网格，最高 120×64。ResizeObserver 只重建投影，不重置旋转。

- 待机约 18 秒一圈；拖动整个场景可接管旋转。
- 水平拖过场景约旋转半圈，俯仰固定在 12°–32°；最后 4°渐进阻尼，反向拖动立即响应。
- 约 45ms 平滑跟随；最近 100ms 位移求平均释放速度并限幅，停顿超过 120ms 不沿用旧速度。
- 水平惯性以 0.8 秒时间常数趋近自转速度；纵向以 0.22 秒衰减，到边界清零。取消指针与捕获丢失清除惯性。
- 方向键调整视角，Home 用约 350ms 复位，再恢复自转。
- 28 个星点以 1.2–2.6 秒周期错开闪烁；首颗流星约 1.2 秒后出现，此后每 2–3.5 秒一次，8–11 字符尾迹，持续 1–1.35 秒。流星优先穿过左下留白，按深度被星球遮挡。拖动不新增流星。
- 首页标签不活动、页面隐藏或场景滚出视口时暂停；恢复不补算时间。减少动态效果关闭所有自动运动和惯性，保留直接拖动、键盘操作。

球面使用更明显的连续明暗纹理，并叠加缓慢流动；星环沿圆周运行明暗波和亮点，环带也有独立流动。所有变化仍由同一时钟驱动，减少动态效果时完全冻结。

## 代码边界

PlanetScene 定义页面局部类型；planetMotion 负责纯运动规则；asciiPlanet 负责投影、背景字符与深度绘制；usePlanetAnimation 负责单一动画循环、输入采样、时钟、随机和浏览器可见性。React 只更新星球组件，不将逐帧状态放进全局 store。后端 API 和数据库未变更。

## 验证

- 前端 54 项单元测试通过（含 8 项运动与渲染测试）。
- 星球 5 项 Playwright 场景通过：桌面拖动／惯性／复位、手机触摸和减少动态效果、响应式截图与性能、标签／隐藏／离屏暂停与恢复、固定时钟及随机种子的流星画面。
- 格式、TypeScript 与生产构建检查通过。
- 最大 120×64 字符渲染 P95 约 0.7ms，测试中最大约 1.1ms；实际页面 1.8 秒采样约 29.98fps，没有观察到长任务。此数据来自当前机器短时间采样，不承诺所有设备达到相同帧率。
- 性能原始数据：acceptance/planet-performance.json、acceptance/planet-frame-pacing.json。
- 截图：screenshots/ascii-planet/desktop.png、mobile.png、idle-meteor.png。静态布局用减少动态效果；流星截图固定时间与随机种子。
