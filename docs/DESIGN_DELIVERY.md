# 内容驱动设计与两挡思考：收尾交付

2026-11-08，分支 `feat/content-driven-design`。本轮结束实现与实验，默认启用 v8 内容驱动设计；不继续为微小交互不足追加提示词。设置 `VIBROWSER_DESIGN_WORKFLOW=false` 后重启可回到原生成流程。已有页面及书签不重写。

## 已交付

- 修复复制真实内容、嵌套筛选、CSS 数学表达式兼容和风格元数据类型兼容。元数据转换不改写正文、动作或实体事实；品牌仍严格要求字符串。
- 评审区分实际问题与可选美化，限制改进范围；细微不精致不要求重新设计。可选阶段失败保留已通过校验的页面。
- 地址栏提供标准／深入两挡，与幻觉／认真模式独立。官方标准使用 enabled/low、深入使用 enabled/high，输出预算均为 48000；标签、历史、重试和书签沿用提交时快照。兼容接口保留原标准配置，暂不开放深入。
- 新站由模型提出内容相关的空间和字体构想，按地址稳定选择；近期视觉参照仅含测量信息，无人工模板。沿站点探索继承品牌和实体，不重新抽取风格。
- 保持独立数据类、封闭状态、消息 plan(connection)、Table SQL 和事务外模型调用的课程结构。

## 真实调用结果

固定六题涵盖教师主页、文案工具、日历、咖啡器具比较、技术文档、旅行随笔。原产品参数批次最终 **5/6**、首轮 **3/6**，27 次请求、1235 秒。随笔因风格元数据类型不匹配失败；修复解码后仅对该失败页显式重试，首轮正文通过，3 次请求、159 秒。没有重跑其他五题寻找更好的样本，也没有把原批次改写为 6/6。
