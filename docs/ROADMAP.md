# Vibrowser 开发路线

更新：2026-11-03。Day 1–3 表示三个开发日，不代表已经确认的日历截止日期。

## 成功标准

完成一次 3–5 分钟演示：输入陌生网址 → 生成可交互网页 → 点击站内链接 → 打开相关虚构文件 → 返回旧页面 → 刷新或重启后内容仍然一致。

关键依赖：**契约与样例 → 无 AI 全栈闭环 → 真实生成与校验 → 持久化一致性 → 展示打磨**。

所有功能项目前均未实现；已完成的工作仅为仓库初始化、Git 身份设置和本规划。

## 优先级与取舍

| 优先级 | 内容 | 最低交付边界 |
| --- | --- | --- |
| P0 | 浏览器外壳 | 地址栏、少量标签页、每个标签的前进/后退/刷新、加载/失败页 |
| P0 | AI 网页 | 一次生成完整 PageSpec，受控组件、可用链接、至少三种视觉主题 |
| P0 | AI 虚构文件 | `.md`、`.txt`、`.json`，生成、预览、保存；不访问真实磁盘 |
| P0 | 持久化与上下文 | 页面与 SiteProfile 入库，缓存复用，重启恢复；浏览器历史可先存 localStorage |
| P0 | 稳定性 | Schema/语义校验、有限重试、生成去重、超时、失败可重试 |
| P1 | 生成式搜索 | 只实现 `generate/search` 一种操作，结果作为独立页面保存 |
| P1 | AI 配图 | 权限核验通过后接入；文字先显示，图片失败不影响阅读 |
| P1 | 真实网页入口 | 用户显式选择外部打开；嵌入预览属于额外增强 |
| P2 | 扩展体验 | 自由 HTML/CSS、自然语言编辑、更多表单/交互、跨站世界设定增强 |

三天不做：完整浏览器内核、真实网页代理、宿主文件管理器、登录/多租户、知识图谱、通用 Agent、动态编译 TSX、支付与购物车业务后端。

## Day 1：锁定契约，跑通无 AI 闭环

| 顺序 | 任务 | 产物 / 验收 |
| --- | --- | --- |
| D1.1 | 定义 `PageSpec`、`FileSpec`、`BrowserAction`、`SiteProfile` 与 API 状态 | `contracts/` 下版本化 Schema、有效/无效样例；明确 URL、ID、错误格式 |
| D1.2 | 创建 React/TS、Scala 3/http4s 和 PostgreSQL 开发骨架 | 锁定依赖版本、数据库迁移、本地启动说明；API 能读写数据库 |
| D1.3 | 实现浏览器外壳、受控 Renderer、文件预览 | 地址栏可展示 Mock 网站与文件；链接与 toggle 可操作 |
| D1.4 | 实现导航、缓存、页面状态查询 | 前端 → Scala → PostgreSQL → 前端全链路打通；刷新命中保存内容 |
| D1.5 | 小规模核验可用文本 API 与生图权限 | 记录模型 ID、结构化输出能力、延迟、错误响应；Key 留在本地后端 |

**退出条件：**不接 AI 也能完成网站 → 子页面 → 文件 → 返回的演示；前后端对同一批契约样例的判断一致。

API 核验无法完成时，Mock 模式继续支撑开发，但不得标记“真实 AI 生成已完成”。先确认一种文本 provider 即可；图片权限问题不阻塞 Day 2。

## Day 2：接入真实生成，保证页面持续存在

| 顺序 | 任务 | 产物 / 验收 |
| --- | --- | --- |
| D2.1 | 后端 LLM adapter 与 Prompt | 配置化地址/模型；输入 URL、来源页面摘要、SiteProfile 和受控组件规则 |
| D2.2 | 解析与双层校验 | 检查空输出、截断 JSON、Schema 和业务规则；最多一次修复请求，失败返回可读错误 |
| D2.3 | 后台任务与数据库事务 | 页面首次生成、失败重试、同 URL 请求去重；保存成功才标记 ready |
| D2.4 | 关联页面与文件生成 | 同站延续品牌/主题；虚构文件参考近期摘要；JSON 文件必须可解析 |
| D2.5 | 导航一致性与恢复 | 刷新不重新生成；快速切换页面时旧请求不能覆盖当前页面；重启后生成中任务可恢复或明确失败 |
| D2.6 | 可选搜索闭环 | 来源 actionId + query → 后端验证 → 搜索结果页保存；重复提交可去重 |

**退出条件：**至少两个新站点可以现场生成并点击进入子页；三种虚构文件可预览；重启后旧内容一致；并发访问同一地址只启动一个有效生成任务。

若 Day 2 结束仍未满足 P0，Day 3 全部用于完成 P0，取消搜索、生图、真实网页嵌入和新组件。

## Day 3：打磨与答辩

| 顺序 | 任务 | 产物 / 验收 |
| --- | --- | --- |
| D3.1 | 浏览体验 | 标签页与历史恢复、错误重试、地址变化、真实生成阶段提示、不同主题视觉校对 |
| D3.2 | 可选生图 | 最多三张/页，异步任务、占位、超时、资源持久化；失败不改变 ready 页面状态 |
| D3.3 | 验证与修复 | 跑下方核心验收矩阵；完成后冻结功能 |
| D3.4 | 演示材料 | README 启动步骤、架构图、环境变量示例、演示脚本和预存演示数据 |

**退出条件：**干净环境按 README 可启动，真实 AI 演示与预存演示模式均可用，后者清楚标识；能够解释前端、Scala、数据库和 AI 各自的责任。

## 核心验收矩阵

| 场景 | 必须看到的结果 | 建议验证方式 |
| --- | --- | --- |
| 同地址首次/再次访问 | 首次生成；再次直接读缓存，内容与 ID 不变 | API 集成 + provider 调用计数 |
| 站内相对链接 | 按来源地址解析，站点设定延续 | URL 单元测试 + 浏览器端到端 |
| 本地 toggle | 本地状态变化，不调用 LLM | 前端交互测试 |
| `.md/.txt/.json` 文件 | 正确预览和持久化，JSON 不合法时拒绝 | 契约样例 + 集成 |
| 不合法模型输出 | 未知组件/Action、重复 ID、过深嵌套被拒绝；修复最多一次 | 校验单元测试 + Mock provider |
| 模型超时/空输出/限流 | 有界失败，无无限轮询；用户可显式重试 | 故障注入 |
| 同 URL 并发 | 一个有效任务，客户端共享 pageId/jobId | 数据库并发集成测试 |
| 后退、刷新、快速导航 | 不重复生成，迟到响应不覆盖当前页面 | 浏览器端到端 |
| 后端重启 | 已完成内容仍在；旧任务不永久卡住 | 重启冒烟检查 |
| 输入危险地址/生成代码 | file 不读磁盘，javascript 等协议被拒绝，HTML/脚本不执行 | 边界样例 + 渲染检查 |
| 图片服务不可用 | 文本页面仍可浏览，图片显示失败或占位 | 可选功能集成测试 |

## 演示路径

1. 输入 `https://moon-coffee.example`，解释内容是现场生成的虚构站点。
2. 点击 `/menu`，展示链接可用且品牌与主题保持一致。
3. 打开 `file:///notes/moon-trip.md`，展示参考近期内容生成的虚构文件。
4. 后退并刷新，展示内容不变、数据库缓存命中。
5. 展示一次失败与重试；有余量再展示配图或搜索。

离线备份使用预存内容，并明确标识“预存演示”；不要用预存内容冒充实时生成。

## 三天之后

- 首先完善可观测性：生成耗时、缓存命中率、校验失败率、provider 使用量。
- 然后扩展组件和可控 Action，再加入自然语言编辑与版本历史。
- 最后评估隔离 HTML/CSS 模式和更丰富的世界状态。新能力需有独立契约与测试，不破坏已有页面。
