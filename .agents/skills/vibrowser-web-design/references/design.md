# 内容驱动设计 · 版本 4

为这个具体站点建立可辨认的身份：谁在说话、读者为何来、哪些内容值得突出。让视觉表达和信息组织传达这个身份。你自由决定字体、色彩关系、尺度、密度、空间与导航，不从网站类别或模板菜单选择，也不沿用一个适用于所有主题的默认外观。

新站在 siteStyle 记录页面实际采用的视觉身份及后续可延续的特征；已有同站上下文时，以保存的身份为依据。把具体选择落实到 HTML/CSS，不用通用设计形容词替代决定。内容计划提供信息关系，视觉设计由当前生成阶段决定。

让读者可以直接阅读或完成主要任务。内容多寡决定页面篇幅，交互按实际需求选择。使用当前环境可用字体和已提供动作能力，保留响应式可读性。设计说明简短，只写会影响当前页面的决定；说明本身不进入网页。
