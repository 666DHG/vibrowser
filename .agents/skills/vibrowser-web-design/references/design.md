# 内容驱动设计 · 版本 2

先确定访问者在这一页要完成的事情，再判断现有内容如何支持这个任务。信息关系、重要程度、长度和可操作性决定布局。资料少时保持简洁，资料丰富时允许长页面与高密度；不要为了填满版面编造栏目。

自行提出信息组织、阅读顺序、空间关系和字体层级。使用自由描述，不从预设布局或网站类型菜单中选择。新站先从它的内容、受众和用途建立视觉身份，给出这些特征如何影响排版、字体、导航与密度的具体理由；没有继承资料时，不声称存在既定品牌或设计规范。同站仅延续上下文实际提供的品牌、字体、色彩和导航习惯，内容结构仍随当前任务改变。

首屏应该让人识别主题并开始完成主要任务。决定哪些信息立即可见，哪些适合后续浏览、展开或检索。大标题、侧栏、卡片、分栏、页脚和搜索框都只是可选手段，不是页面必须拥有的部件。不按网站类别分配动作；只为实际内容和任务提供有用控件。

中文排版要考虑连续阅读的行宽、正文行高、长标题换行和混排。使用环境可用的系统字体栈，明确正文、标题、数据和导航之间的层级。装饰、色彩和字形可以承担站点身份和内容表达，只需保持文字可辨、操作可达；低装饰、单强调色、窄栏或米白底并不天然优于其他选择。不能只用“简洁现代、专业克制”等通用形容词替代设计决策，也不要求每站夸张或每次随机换色。

结构表达内容关系。重复容器应该确有可比较的条目；编号应该对应顺序；留白应该帮助分组。独特性可以来自文字组织、导航方式、尺度对比和信息密度；避免只改强调色却沿用不适合内容的结构。允许朴素、密集、实验性或强视觉表达，按当前内容取舍，不以某一种风格作为所有网站的质量标准。

提出必要的交互及其作用，只有当前协议可以实现的行为才承诺。所有设计决策写成简短工作说明，不要求详述内部推理，不把说明、审核信息或免责声明写入页面。
