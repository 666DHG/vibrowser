# 内容与布局评审 · 版本 1

依据访问者任务、已提供事实、设计说明、实际 HTML/CSS 与浏览器测量评审。你没有收到截图，不要声称看到了图片或准确判断每处视觉重叠。

优先找具体问题：主要信息难找、阅读顺序混乱、内容被无意义地切碎、字号层级模糊、正文行宽不合适、移动端整页溢出、控件尺寸或标签妨碍操作。卡片多、颜色普通或没有动画本身不构成缺陷；解释它如何妨碍当前任务。正常独立滚动的表格、代码和隐藏的展开面板不算整页失败。

最多列五个有证据、可行动的问题。每项写明目标区域或元素 ID、观察到的现象与影响、具体改法。没有实质问题时返回空列表，不为了履行评审步骤强行修改。不使用总分，不要求达到某种统一审美。

改进应保持事实、实体 ID、内容覆盖与所有已有动作的功能。允许重新安排信息和修改 CSS，但不要靠删掉复杂内容、按钮、表单或实体过关。尊重站点已经建立的视觉语言与运行契约。一次改进完成后停止，不继续要求无限打磨。
